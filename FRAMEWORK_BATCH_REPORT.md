## Reproducing QA

Run from the worktree:

```text
pnpm install --frozen-lockfile
pnpm build
pnpm exec tsc --noEmit
pnpm lint
node scripts/framework-qa.mjs
```

For browser checks, start the local site, set `PLAYWRIGHT_MODULE` to an available Playwright module, `BROWSER_EXECUTABLE` to a compatible local browser (optional when Playwright's browser is installed), and `FRAMEWORK_BASE_URL` to the local server. Run the same script. `FRAMEWORK_QA_OUTPUT` optionally chooses a temporary screenshot/results directory.
